# Udemy-clone-Website
Project Overview
A simple Udemy clone created using HTML and CSS.

Focused on replicating the layout and design of the Udemy website.

Built to practice front-end development skills.

Features
Responsive homepage design.

Navigation bar with logo and menu links.

Course section with course cards.

Footer section with basic details.

Technologies Used
HTML5-for webpage structure.

CSS3 -for styling and layout.

How to Run
Clone the repository.

Open the project folder.

Run the index.html file in any browser.
